# Crédits

Swarmageddon (ex-Ruée Nocturne) est un jeu de **Jimmy Haggege**. Le code a été écrit avec [Claude Code](https://claude.com/claude-code) (Anthropic), phase par phase, à partir du plan de conception `PLAN.md`.

Depuis la phase 20 (1.15.0), les armes et une partie du décor sont des modèles 3D KayKit (voir plus bas), depuis la phase 46 (1.44.0) les neuf personnages sont des modèles KayKit remis en proportions humanoïdes, animés par les clips de la bibliothèque d'animations Quaternius (les modèles Quaternius des phases 25 à 45 ne servent plus que de squelette source), et depuis la phase 26 (1.21.0) les ennemis sont des morts-vivants construits avec le kit Quaternius. Depuis la phase 36 (1.31.0), les bruitages et la musique sont des enregistrements sous licence libre (voir « Sons et musique »). Le reste est produit par le code : les effets et les ouvrages sont des primitives low-poly générées au lancement, et des sons synthétisés par Web Audio prennent le relais tant que les fichiers audio ne sont pas chargés. Il n'y a pas de sprite.

Les fichiers de `public/models/` sont produits par `npm run assets` (`tools/assets/`) : animations utiles seulement, accessoires choisis, compression meshopt. quaternius.com n'est pas joignable depuis l'environnement de build : les personnages viennent du dépôt public [godot-3d-player-controller-v2](https://github.com/kirbycope/godot-3d-player-controller-v2) (fichiers Quaternius inchangés, licences CC0 jointes), les objets tenus du miroir [quaternius-showcase](https://github.com/trebeljahr/quaternius-showcase). Les packs d'origine ne sont pas dans le dépôt.
