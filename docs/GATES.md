## Décisions prises en cours de route

(Chaque décision non couverte par PLAN.md : date, question, option retenue, raison.)

- **2 nov. 2026 — TypeScript 7 → 6.0.** Le kit installait `typescript@7.0.2`, port natif (Go) sans API compilateur JS. `typescript-eslint` exige `typescript < 6.1`. Option retenue : `typescript@^6.0.3` (même `tsc --noEmit`, mêmes types). Écartée : garder TS 7 et ajouter un second compilateur pour l'outillage.
- **2 nov. 2026 — Lighthouse « PWA = 100 ».** Lighthouse a supprimé la catégorie PWA en v12 (mai 2024). La porte se mesure avec `lighthouse@11.7.1 --only-categories=pwa` (dernière version qui l'a), et Lighthouse 13 pour perf/accessibilité. En CI, l'étape est `continue-on-error` tant qu'elle n'est pas stabilisée sur Ubuntu.
- **2 nov. 2026 — Icônes sans `sharp`.** `tools/icons.ts` rend `assets/icon.svg` dans le Chromium de Playwright (déjà requis). Zéro dépendance native pour 4 PNG ; les PNG sont commités dans `public/` pour que `npm run build` ne dépende pas d'un navigateur.
- **2 nov. 2026 — Node 22 en CI.** Les workflows du kit visaient Node 20 ; Vite 8 exige ≥ 22.12. En local Node 25 fonctionne (avertissement `EBADENGINE`).
- **2 nov. 2026 — Pas d'écran « Hello world ».** PLAN.md §5 prévoyait un cube ×1000 pour la phase 0 ; la base v0.1 étant jouable, c'est elle qui est déployée (le prompt de lancement demande de compléter, pas de remplacer).
- **2 nov. 2026 — Test hors-ligne.** `context.setOffline(true)` de Playwright coupe la navigation avant le service worker (`ERR_INTERNET_DISCONNECTED`). Le test coupe le réseau avec `context.route('**/*', abort)` : seules les réponses servies par le service worker passent.
- **2 nov. 2026 — `seed(n)` de debug.** Le décor dépend de la seed du monde et n'est construit qu'une fois ; `debug.seed(n)` garde la seed de décor et fixe le décalage du rng (`startGame(variant)`), ce qui donne une partie reproductible sans reconstruire le décor.
- **2 nov. 2026 — `.gitignore` du kit.** `sim/` ignorait aussi `src/sim/` : corrigé en `/sim/` et commit initial amendé avant tout push.
- **2 nov. 2026 — Projet Firebase.** `ruee-nocturne` créé par la CLI (nom d'affichage sans accent : refusé par l'API), site Hosting par défaut `ruee-nocturne.web.app`. Le fichier personnel `all time frame.docx` à la racine est ignoré par git.
